How it works

    

      Fused kernel — each thread streams the database and keeps its own k-best in registers; a
      block-level merge in shared memory produces the block's top-k without ever writing the n×q distance
      matrix to memory. Two-pass — the classical alternative: one kernel materialises all n·q
      distances, a second scans them. The sweep above measures the memory traffic we save.
    

    

      Exactness — every verified run compares top-1 indices exactly and k-th distances against a
      double-precision CPU reference (rel. tolerance 1e-3, float vs double). Sharding — the MPI
      binaries split the database across ranks (one GPU per rank), keep local top-k, then merge to a
      global top-k; communication stays O(size·q·k), independent of n.
